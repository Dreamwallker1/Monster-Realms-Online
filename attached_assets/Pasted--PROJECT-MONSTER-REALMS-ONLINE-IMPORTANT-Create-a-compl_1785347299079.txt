# PROJECT: MONSTER REALMS ONLINE

## IMPORTANT

Create a complete online browser game inspired by classic monster collecting games, but it must be a 100% ORIGINAL intellectual property.

DO NOT use Pokémon names, Pokémon artwork, Pokémon sounds, Pokémon designs, Poké Balls, Pokédex or any copyrighted assets.

Everything must be original while preserving the fun of exploration, collecting and turn-based battles.

The code should be clean, modular, scalable and production-ready.

# IMPORTANT GAME DESIGN PRINCIPLES

1. Exploration should be more rewarding than grinding.
2. Every step should feel meaningful.
3. Rare discoveries should create excitement.
4. Skill should always matter more than money.
5. Monetization must never become Pay To Win.
6. The game should encourage long-term retention through exploration, collection, social interaction and seasonal competition.
7. Build the project using a clean folder structure, reusable components, scalable networking and maintainable code suitable for a commercial live-service game.

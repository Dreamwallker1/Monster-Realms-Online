KRİTİK BUG:

Haritada Myth encounter penceresi açılıyor fakat “Battle!” butonuna bastığımda battle arena açılmıyor. Buton çalışıyor gibi görünüyor ancak kullanıcıya hata gösterilmiyor.

Önce çalışan uygulamada problemi yeniden üret. Browser console, Network ve API server loglarını incele. Tahmin ederek patch yazma.

Şunları sırayla kontrol et:

1. EncounterPopup.tsx içindeki handleBattle
2. POST /battles isteğinin status kodu ve gerçek response’u
3. Oyuncuya ait yarım kalmış active battle kaydı
4. Sunucudaki pending encounter kaydı
5. Gönderilen regionId ve speciesId değerleri
6. Aktif takım Myth’inin currentHp değeri
7. waitForBattleFocus ve BATTLE_FOCUS_READY_EVENT
8. BATTLE_FOCUS_EVENT ile BATTLE_RELEASE_EVENT çakışması
9. startBattle(battle.id, battle) çağrısının çalışması
10. BattleOverlay’ın açılmasını engelleyen state veya runtime hata

UYGULAMA KURALLARI:

- POST /battles başarılı olmadan encounter penceresini kapatma.
- API başarılı olduğunda battle state’ini güvenli şekilde kaydet.
- Kamera sinyali gelmezse maksimum 2.6 saniye sonra arena yine açılsın.
- BATTLE_RELEASE yalnızca gerçek active → inactive geçişinde çalışsın.
- Yarım kalmış eski battle varsa gerçek devam eden battle’a zarar vermeden çöz.
- API hatasını yalnızca console’a yazma; encounter penceresinde kullanıcıya göster.
- Hata düzeltmesi dışında hiçbir dosyaya gereksiz değişiklik yapma.
- Patch veya restore dosyalarını projeye ekleme.
- Mevcut commit geçmişini değiştirme.
